## 打包的数据集

本包 `data/` 目录包含以下第三方数据，**不适用 MIT 许可**：

| 数据集 | 来源 | 许可 |
| --- | --- | --- |
| 机场 / 跑道 / 导航台 | [OurAirports](https://ourairports.com/data/) | Public Domain |
| VFR 报告点（VRP） | [openAIP](https://www.openaip.net) | CC BY-NC 4.0 |
| FIR / UIR | [VATSpy](https://github.com/vatsimnetwork/vatspy-data-project) | CC BY-SA 4.0 |

- openAIP 数据需要署名，且仅限非商业用途。
- VATSpy 数据需要署名，并以相同方式共享（CC BY-SA 4.0）。
- 各数据集的完整许可说明见 `DATA-LICENSES.md`。

## 第三方服务

- **FlightAware**：通过浏览器抓取网页数据，属非官方接入，可能违反其服务条款。仅供个人学习与测试，风险自负。
- **FlightRadar24**：使用其公开网页接口或官方 API；非官方网页接口可能随时变更。
- **adsb.lol**：开放 ADS-B 聚合数据，覆盖取决于社区接收站。
- **aviationweather.gov**：METAR / TAF 数据，Public Domain。
- **SkyLink**：NOTAM API，需要用户自行申请 API key。
- **SkyVector / Jeppesen**：World 航图为 Jeppesen 授权数据，仅供个人测试，请勿公开分发。
